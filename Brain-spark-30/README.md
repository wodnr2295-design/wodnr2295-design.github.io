# 브레인 스파크 60 · BRAIN SPARK 60

1분 동안 13가지 미니게임으로 **두뇌 회전**과 **반응속도**를 측정하는 캐주얼 웹 게임입니다.
설치 없이 브라우저에서 바로 실행되고, 모든 기록은 기기(`localStorage`)에 저장됩니다.

라이브: https://wodnr2295-design.github.io/Brain-spark-30/ (주소는 30초 시절 링크를 그대로 유지)

## 게임 구성

| 종목 | 유형 | 내용 |
| --- | --- | --- |
| 🚦 신호등 캐치 | 반응 | 초록불에만 탭, 보라색 신호는 훼이크 |
| 🎯 타겟 스나이퍼 | 반응 | 폭탄을 피하고 황금 타겟만 명중 |
| 🔢 1→9 순서 터치 | 반응 | 1부터 9까지 오름차순으로 빠르게 |
| 🧭 방향 러시 | 반응 | “같은 방향 / 반대 방향” 지시에 맞춰 입력 |
| 🎨 스트룹 컬러 트랩 | 두뇌 | 글자색과 글자 뜻이 충돌하는 스트룹 과제 |
| ⚡ 번개 암산 | 두뇌 | 사칙연산·대소비교를 빠르게 |
| 🧩 순간 기억력 | 두뇌 | 3×3~4×4 격자의 반짝임 순서를 기억 |
| 🔍 다른 하나 찾기 | 두뇌 | 회전·모양이 미묘하게 다른 기호 찾기 |
| 🔷 도형 매칭 | 두뇌 | 같은 기호 조합을 순서까지 맞추기 |
| ⚖️ 순간 판별 | 반응 | “더 큰 수 / 짝수” 같은 지시를 읽고 두 수 중 하나를 초고속 터치 |
| ⏱️ 초시계 스톱 | 반응 | 흐르는 게이지를 노란 존 한가운데에서 정확히 멈추기 |
| 🔮 패턴 빈칸 | 두뇌 | 등차·배수·반복 순환 규칙을 읽고 다음 조각 고르기 |
| 💡 플래시 그리드 | 반응 | 3×3 격자에 번쩍이는 칸을 연속으로 타격 |

- **1분 종합 챌린지**: 13종이 매 판 랜덤으로 전환(직전 두 종목은 제외), 콤보 배수 `x1.0 → x4.0`
- **종목별 트레이닝**: 원하는 종목만 1분 집중 연습, 종목별 최고 기록 저장

## 화면과 기능

- **로비** — 프로필 카드(닉네임 편집·칭호·아바타·프레임·티어), 코인, 최고 점수, 10판 보상 진행도, 최근 기록, 도전장 배너
- **결과** — 점수·등급(S+~D)·평균 반응(ms)·정답률·최대 콤보·두뇌/반응 밸런스 바·획득 코인·10판 보상 +1·도전장 링크 복사
- **도전장 링크** — 닉네임·점수·평균 반응·정답률·콤보·아바타/프레임/칭호를 담은 `?c=` 링크를 복사(Web Share 지원 시 공유 시트)해서 친구에게 전송. 받은 쪽은 자동으로 친구 목록·랭킹에 등록되고 로비 배너에서 바로 도전
- **내 기록** — 누적 통계, 점수 추이 차트, 최근 기록 리스트, 도전장 링크 복사, 기록 초기화
- **랭킹** — 시드 리더보드 + 도전장 친구 + 내 최고 기록이 한 줄로 정렬(친구는 `친구` 배지), 종합/트레이닝 전환(종목별), 친구 삭제·전체 삭제
- **10판 보상** — 1·3·5·7판 코인, 10판 스페셜 상자(700 코인 + 한정 테마·칭호), 사이클 반복
- **커스터마이징** — 테마 6종, 아바타 9종, 프레임 6종, 터치 파티클 5종, 칭호 7종 (구매·장착 즉시 반영)
- **오디오** — Web Audio로 합성한 BGM·효과음, 각각 켜고 끄기 가능
- **모션** — 60fps GPU 트랜지션, 터치 파티클(캔버스), 콤보/오답 피드백, `prefers-reduced-motion` 존중

## 밸런스

- 30초 → 60초로 늘면서 등급 기준·티어 기준·시드 랭킹·코인 보상을 함께 조정했습니다. (등급 S+ 15,600 / S 12,000 / A 9,200 / B 6,800 / C 4,600)
- 코인은 `점수/75 + 정답률 보너스 + 콤보 보너스`(최대 300)로 한 판에 쌓입니다.
- 기존 `localStorage` 키(`brainspark30.v1`)와 저장 구조는 그대로라서 30초 시절의 코인·커스터마이징·기록이 유지됩니다.

## 실행

정적 파일만으로 동작합니다. ES 모듈을 사용하므로 `file://`이 아닌 HTTP로 열어야 합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 테스트

```bash
python3 tests/qa.py         # 로비·탭·13종 게임·60초 플레이·구매·보상·도전장 링크·새로고침 유지·반응형
python3 tests/live_check.py # https://wodnr2295-design.github.io/Brain-spark-30/ 라이브 검증
python3 tests/visual.py     # 화면 캡처용
```

`?test=1`로 열면 QA용 훅(`window.__BS30_TEST__`)이 켜지고, 문제 요소에 `data-ok`가 붙습니다.
일반 사용에는 아무 영향이 없습니다.
