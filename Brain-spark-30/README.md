# 브레인 스파크 30 · BRAIN SPARK 30

30초 동안 9가지 미니게임으로 **두뇌 회전**과 **반응속도**를 측정하는 캐주얼 웹 게임입니다.
설치 없이 브라우저에서 바로 실행되고, 모든 기록은 기기(`localStorage`)에 저장됩니다.

라이브: https://wodnr2295-design.github.io/Brain-spark-30/

## 게임 구성

| 종목 | 유형 | 내용 |
| --- | --- | --- |
| 🚦 신호등 캐치 | 반응 | 초록불에만 탭, 보라색 신호는 훼이크 |
| 🎯 타겟 스나이퍼 | 반응 | 폭탄을 피하고 황금 타겟만 명중 |
| 🔢 1→9 순서 터치 | 반응 | 1부터 9까지 오름차순으로 빠르게 |
| 🧭 방향 러시 | 반응 | “같은 방향 / 반대 방향” 지시에 맞춰 입력 |
| 🎨 스트룹 컬러 트랩 | 두뇌 | 글자색과 글자 뜻이 충돌하는 스트룹 과제 |
| ⚡ 번개 암산 | 두뇌 | 사칙연산·대소비교를 빠르게 |
| 🧩 순간 기억력 | 두뇌 | 3×3~4×4 격자의 반짝임 순서를 기억 |
| 🔍 다른 하나 찾기 | 두뇌 | 회전·모양이 미묘하게 다른 기호 찾기 |
| 🔷 도형 매칭 | 두뇌 | 같은 기호 조합을 순서까지 맞추기 |

- **30초 종합 챌린지**: 9종이 매 판 랜덤으로 전환, 콤보 배수 `x1.0 → x4.0`
- **종목별 트레이닝**: 원하는 종목만 30초 집중 연습, 종목별 최고 기록 저장

## 화면과 기능

- **로비** — 프로필 카드(닉네임 편집·칭호·아바타·프레임·티어), 코인, 최고 점수, 10판 보상 진행도, 최근 기록
- **결과** — 점수·등급(S+~D)·평균 반응(ms)·정답률·최대 콤보·두뇌/반응 밸런스 바·획득 코인·10판 보상 +1
- **내 기록** — 누적 통계, 점수 추이 차트, 최근 기록 리스트, 요약 복사, 기록 초기화
- **랭킹** — 시드 리더보드에 내 최고 기록이 자동 반영·하이라이트, 종합/트레이닝 전환(종목별)
- **10판 보상** — 1·3·5·7판 코인, 10판 스페셜 상자(500 코인 + 한정 테마·칭호), 사이클 반복
- **커스터마이징** — 테마 6종, 아바타 9종, 프레임 6종, 터치 파티클 5종, 칭호 7종 (구매·장착 즉시 반영)
- **오디오** — Web Audio로 합성한 BGM·효과음, 각각 켜고 끄기 가능
- **모션** — 60fps GPU 트랜지션, 터치 파티클(캔버스), 콤보/오답 피드백, `prefers-reduced-motion` 존중

## 실행

정적 파일만으로 동작합니다. ES 모듈을 사용하므로 `file://`이 아닌 HTTP로 열어야 합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 구조

```
index.html            화면 셸(레이어·HUD·내비게이션)
css/style.css         디자인 시스템, 테마, 인게임/결과 스타일
js/data.js            9종 게임 정의, 상점, 등급·티어, 리더보드 시드
js/store.js           localStorage 상태(프로필·코인·기록·보상 사이클)
js/games.js           9가지 미니게임 구현
js/session.js         30초 세션 엔진(콤보·점수·라운드·결과)
js/ui.js              로비·랭킹·보상·상점·기록·결과 화면
js/audio.js           Web Audio SFX/BGM 신시사이저
js/fx.js              캔버스 터치 파티클, 햅틱
fonts/bs-sans.woff2   Noto Sans KR 서브셋 (SIL OFL 1.1)
tests/qa.py           Playwright E2E (77개 체크)
```

## 테스트

```bash
python3 tests/qa.py     # 로비·탭·9종 게임·30초 플레이·구매·보상·새로고침 유지·반응형
python3 tests/visual.py # 화면 캡처용
```

`?test=1`로 열면 QA용 훅(`window.__BS30_TEST__`)이 켜지고, 문제 요소에 `data-ok`가 붙습니다.
일반 사용에는 아무 영향이 없습니다.

## 폰트

`fonts/bs-sans.woff2`는 Noto Sans KR(SIL Open Font License 1.1)에서 이 앱이 쓰는 문자만 서브셋한 파일입니다.
